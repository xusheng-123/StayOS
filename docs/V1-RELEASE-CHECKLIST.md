- [ ] 确认个人信息处理依据、必要字段、授权、保留期限、清理/匿名化及备份中的个人信息处理规则。
- [ ] 完成生产 HTTPS、证书、可信代理、受限网络、数据库运行/迁移账号及运维身份验收。
- [ ] 指定密钥保管和灾难恢复责任人，落实独立密钥副本、离机备份、执行身份、失败告警和实际恢复演练。
- [ ] 确定 RPO/RTO、备份周期及留存策略，不把本地恢复耗时当作承诺。
- [ ] 完成目标服务器长时间容量、真机弱网和实际岗位人员验收与培训。
- [ ] 明确停机/断网/误操作的申请、人工处置及恢复后核对责任，不允许直接改数据库代替业务流程。

## 5. 仍阻止正式运营的问题

1. 酒店的实名/登记和个人信息处理要求尚未闭环，不能据此开始收集真实住客数据。
2. 当前为本地回环地址与开发配置，真实 HTTPS、网络、代理及生产权限尚未验收。
3. 本地恢复不能替代离机副本、独立密钥、责任人、告警和异机灾备演练。
4. 目标服务器长时间容量、真机现场、留存/清理和应急值守安排尚未完成。

本轮不安装常驻任务、不上传真实备份、不切换开发账号或密钥、不提交 Git。V1.1 及以后仅为已认可路线，未进入本次开发。当前本地收口完成与否须以第 1 节及本次收口记录最终结果为准，不能代替正式运营批准。
